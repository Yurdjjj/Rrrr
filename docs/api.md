# Проект REST API (6-сабақ)

Данная спецификация описывает интерфейс взаимодействия между клиентом (Frontend) и сервером (Backend FastAPI) на основе пользовательских историй `docs/user-stories.md`.

---

## 1. Реестр эндпоинтов

| Метод | Путь | Кто (роль) | Что делает | Story | Таблица |
| :--- | :--- | :--- | :--- | :---: | :--- |
| **POST** | `/api/tests` | `teacher` | Создание черновика теста (название, тема) | US-1 | `tests` |
| **GET** | `/api/tests` | `teacher`, `student` | Получение списка тестов (студентам — только опубликованные) | US-1 | `tests` |
| **GET** | `/api/tests/{id}` | Любой авторизованный | Просмотр информации о тесте и его вопросов (без правильных ответов для студентов) | US-1, US-4 | `tests`, `questions` |
| **POST** | `/api/tests/{id}/questions` | `teacher` (автор) | Ручное добавление вопроса в тест | US-1 | `questions` |
| **POST** | `/api/ai/generate-questions` | `teacher` | Генерация вопросов и вариантов ответа с помощью ИИ по тексту | US-2 | `questions` (в памяти / сохранение в тест) |
| **POST** | `/api/tests/{id}/publish` | `teacher` (автор) | Публикация теста (проверка наличия вопросов) | US-3 | `tests` |
| **POST** | `/api/tests/{id}/attempts` | `student` | Отправка ответов на тест и расчет итогового балла | US-4 | `attempts` |
| **GET** | `/api/attempts/{id}` | `student` (автор попытки) | Просмотр детальных результатов сданного теста и разбора ошибок | US-5 | `attempts` |
| **GET** | `/api/tests/{id}/attempts` | `teacher` (автор теста) | Просмотр списка всех попыток студентов по конкретному тесту | US-6 | `attempts` |
| **GET** | `/api/tests/{id}/export-csv` | `teacher` (автор теста) | Выгрузка ведомости с оценками студентов в формате CSV | US-7 | `attempts` |

## 2. Коды ответов сервера (HTTP Status Codes)

| Код | Значение | Пример в нашем проекте |
| :---: | :--- | :--- |
| **200** | **OK (Успешно)** | Успешное чтение списка тестов, информации о тесте или получение выгрузки CSV. |
| **201** | **Created (Создано)** | Успешно создан новый тест, добавлен вопрос или зафиксирована сданная попытка. |
| **204** | **No Content (Удалено)** | Успешное удаление черновика теста или вопроса (тело ответа пустое). |
| **400** | **Bad Request (Нарушение правила)** | Попытка опубликовать тест без единого вопроса; количество ответов не совпадает с числом вопросов. |
| **401** | **Unauthorized (Не авторизован)** | Отсутствует, просрочен или невалиден JWT-токен авторизации. |
| **403** | **Forbidden (Доступ запрещен)** | Студент пытается создать тест; преподаватель пытается отредактировать/опубликовать чужой тест. |
| **404** | **Not Found (Не найдено)** | Запрошенный тест (`tests/{id}`) или попытка не существуют в базе данных. |
| **422** | **Unprocessable Entity (Ошибка валидации)** | Название теста короче 3 или длиннее 200 символов; неверный JSON-формат запроса. |

## 3. Соответствие: story → endpoint → таблица

Каждая пользовательская история со статусом **Must** строго обеспечена соответствующим эндпоинтом и таблицей базы данных (без пустых ячеек):

| Story | Описание истории | Endpoint | Используемая таблица |
| :---: | :--- | :--- | :--- |
| **US-1** | Преподаватель создает тест и добавляет вопросы | `POST /api/tests`<br>`POST /api/tests/{id}/questions` | `tests`<br>`questions` |
| **US-2** | Преподаватель генерирует вопросы через ИИ | `POST /api/ai/generate-questions` | `questions` |
| **US-3** | Преподаватель публикует готовый тест | `POST /api/tests/{id}/publish` | `tests` |
| **US-4** | Студент сдает тест и получает расчет балла | `POST /api/tests/{id}/attempts` | `attempts` |
| **US-5** | Студент смотрит разбор ошибок и пояснения | `GET /api/attempts/{id}` | `attempts` |
| **US-6** | Преподаватель смотрит попытки студентов | `GET /api/tests/{id}/attempts` | `attempts` |
| **US-7** | Преподаватель экспортирует оценки в CSV | `GET /api/tests/{id}/export-csv` | `attempts` |
