# 🎓 AI TestPlatform (EduTest AI)

> Интеллектуальная образовательная веб-платформа: создание тестов с помощью ИИ для учителей и удобное прохождение тестирования для учеников.

---

## 🎯 Тема (5-сабақ)
Платформа для преподавателей по автоматизированной генерации тестов по материалам лекций с помощью ИИ и прохождению их учащимися с мгновенным разбором ошибок.
- **Мақсатты пайдаланушылар / Целевые пользователи:** Преподаватели колледжей, вузов и репетиторы, регулярно проводящие срезы знаний.
- **Сұхбатқа / Для интервью:** 3–5 преподавателей (колледжи, университетские кафедры, образовательные центры).
- **Рөлдер жүйеде / Роли в системе:** Преподаватель (`teacher`), Студент (`student`).
- **AI идеясы / Идея ИИ:** ИИ анализирует текст лекции/темы, генерирует сбалансированные вопросы с правдоподобными вариантами ответов и формирует понятные объяснения к ошибкам, избавляя преподавателя от многочасовой рутины.
- **Бекітілді / Утверждено:** 18.11.2026 (оқытушы / преподаватель)

## 📌 О проекте

**AI TestPlatform** — это современная EdTech-система, которая автоматизирует рутинную работу преподавателей по составлению проверочных материалов и предоставляет учащимся интерактивную среду для проверки знаний с мгновенной обратной связью.

### Основная концепция
1. **Учитель** загружает тему, текст лекции, конспект или PDF-файл либо задает параметры промптом. Искусственный интеллект за считанные секунды формирует сбалансированный тест с правильными ответами, пояснениями и критериями оценки.
2. **Учитель** валидирует, при необходимости редактирует вопросы и публикует тест (по ссылке, пин-коду или внутри учебной группы).
3. **Ученики** проходят тест в удобном адаптивном интерфейсе.
4. **Система** мгновенно проверяет результаты (включая открытые ответы с помощью ИИ), показывает ученику разбор ошибок, а учителю предоставляет детальную аналитику успеваемости класса.

## 👥 Роли и возможности

### 👨‍🏫 Для учителя
- **Генерация тестов с ИИ**:
  - По теме, параграфу учебника, тексту, ссылке или файлу (PDF, DOCX).
  - Разные типы вопросов: один правильный ответ, несколько ответов, установление соответствия, вопросы с открытым текстовым ответом.
  - Настройка сложности (базовый, продвинутый, олимпиадный), возраста/класса учащихся и количества вопросов.
- **Интерактивный редактор**:
  - Быстрое добавление, удаление и ручная корректировка сгенерированных вопросов.
  - Настройка параметров прохождения: ограничение по времени, количество попыток, перемешивание вопросов и вариантов ответов.
- **Управление доступом**:
  - Генерация разовых ссылок, QR-кодов или пин-кодов доступа.
  - Назначение тестов конкретным классам/группам.
- **Аналитика и журнал**:
  - Сводные отчеты по классу: средний балл, медиана, процент успешности.
  - Анализ "проблемных зон" (вопросы, на которых споткнулось большинство).
  - Экспорт результатов (Excel/CSV, PDF).

### 👨‍🎓 Для ученика
- **Быстрый вход**: без сложной регистрации (по коду/ссылке от преподавателя) или через единый аккаунт учащегося.
- **Комфортное прохождение**:
  - Минималистичный интерфейс, оптимизированный под смартфоны и ПК.
  - Таймер с предупреждением об окончании времени.
  - Сохранение прогресса в реальном времени при сбоях сети.
- **Мгновенный фидбек**:
  - Детальный разбор после отправки: правильные ответы и понятные объяснения от ИИ, почему именно этот ответ верен.
  - Персональные рекомендации по темам, которые стоит повторить.

## 🛠 Технологический стек (рекомендуемый)

- **Frontend**: Next.js (React), TypeScript, Tailwind CSS, shadcn/ui.
- **Backend**: Python (FastAPI) или Node.js (NestJS / Express).
- **База данных & ORM**: PostgreSQL, Prisma или SQLAlchemy.
- **Аутентификация**: NextAuth.js / Supabase Auth / JWT.
- **AI & LLM интеграция**:
  - Модели: Google Gemini API / OpenAI API.
  - Фреймворки: LangChain / LlamaIndex / нативные SDK со структурированным выводом (Structured Outputs / JSON Schema).
- **Кэширование & Очереди**: Redis, Celery / BullMQ (для фоновой генерации больших тестов).

## 🚀 Быстрый старт (Разработка)

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/ai-test-platform.git
cd ai-test-platform
```

### 2. Настройка переменных окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Укажите в `.env`:
- Ключи доступа к ИИ (например, `GEMINI_API_KEY` или `OPENAI_API_KEY`).
- Строку подключения к базе данных (`DATABASE_URL`).
- Секретный ключ сессий (`JWT_SECRET` / `NEXTAUTH_SECRET`).

### 3. Установка зависимостей и запуск
*(Инструкция зависит от выбранной структуры репозитория: монорепозиторий или клиент/сервер)*

```bash
# Пример для Node.js / Next.js
npm install
npm run dev

# Пример для Python FastAPI
poetry install
poetry run uvicorn main:app --reload
```

## 🔒 Безопасность и этика

- **Защита ответов**: правильные ответы и ключи оценивания никогда не передаются на клиентскую сторону во время прохождения теста.
- **Античит**: фиксация переключения вкладок, полноэкранный режим, рандомизация порядка вопросов и вариантов.
- **Безопасность данных**: соблюдение требований защиты персональных данных учащихся.
